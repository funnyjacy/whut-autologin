# WHUT 校园网自动登录 (Tampermonkey)

武汉理工大学校园网认证页（`http://172.30.21.100/tpl/whut/login.html`）的油猴脚本：断网被强制跳到认证页时，自动填账号密码并点击登录，全程零操作；登录成功显示横幅并自动关闭标签页。

## 功能

- **自动登录**：页面打开即自动填账号密码并点登录（复用页面自身的 `checkForm()`，CSRF 自动处理）
- **在线检测**：先查 `/api/account/status`，已在线则什么都不做，避免重复认证
- **失败即停**：密码错误（code 1）或需要验证码（code 2）时，顶部红色横幅提示并停止自动重试，交还手动处理，不会死循环刷请求
- **成功关页**：成功（code 0）显示绿色横幅，1 秒后尝试关闭标签页
- **拦截小窗**：拦截 `window.open('success.html')`，登录成功后不再弹出"在线状态"小窗

## 安装

1. 浏览器装好 [Tampermonkey](https://www.tampermonkey.net/)
2. Tampermonkey 图标 → 添加新脚本 → 粘贴 [`whut-autologin.user.js`](whut-autologin.user.js) 全部内容
3. 把开头的 `MY_USERNAME` / `MY_PASSWORD` 改成自己的账号密码（⚠️ 明文存放，请勿把改过的脚本再发布出去）
4. 保存即可

## 注意

- 账号 = 校园卡卡号后六位，密码 = 智慧理工大密码
- 登录失败会触发服务器验证码（code 2），此时脚本主动停手，需手动完成
- 手动打开的标签页 Chrome 不允许脚本关闭（只允许关脚本自己开的标签），横幅照常显示，关页需手动
- 匹配范围仅 `http://172.30.21.100/tpl/whut/login.html*`，其他页面不受影响
